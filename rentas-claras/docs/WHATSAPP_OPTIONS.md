# RentasClaras: Opciones GRATUITAS para WhatsApp Masivo

## 🎯 El Problema Real
- 32 inquilinos con **montos DIFERENTES**
- Solo enviar a los que **NO han pagado**
- Hacerlo en **UNA acción**, no 32 copy-pastes

## 💡 La Verdad
Para envío masivo personalizado real → **necesitas API**.
Pero la API de Meta **ES GRATIS** (primeros 1,000 mensajes/mes).

---

## ✅ OPCIÓN 1: WhatsApp Business App + Broadcast List (GRATIS, MANUAL)

**Cómo funciona:**
1. Descargar "WhatsApp Business" (app gratuita, diferente al WhatsApp normal)
2. Crear una "Lista de Difusión" con los 32 inquilinos
3. Escribir UN mensaje → llega a los 32 al mismo tiempo

**Requisitos:**
- Los inquilinos deben tener tu número guardado en sus contactos
- Si no lo tienen guardado, NO les llega el mensaje

**Tiempo:**
- Setup: 10 minutos
- Envío mensual: 2 minutos (escribir mensaje, enviar)

**Limitación:**
- Máximo 256 contactos por lista de difusión
- Para 32 inquilinos, perfecto ✓

### 📱 Cómo configurar:
```
1. Descarga "WhatsApp Business" de la App Store/Play Store
2. Registra el número de tu papá (puede ser el mismo que ya usa)
3. Ve a Chats → Menú (⋮) → "Nueva difusión"
4. Selecciona los 32 inquilinos
5. ¡Listo! Cada mes, abre esa lista y envía el recordatorio
```

**VEREDICTO: ✅ MEJOR OPCIÓN PARA EMPEZAR**
- Gratis
- Sin programación
- Tu papá puede hacerlo solo

**Requisitos:**

**Tiempo de setup:** 2-3 días (por la verificación)

**Cuándo usarlo:**

- Cuando quieras que el sistema envíe automáticamente el día 1

**VEREDICTO:** Bueno para el futuro, pero overkill para MVP
